# Triage Labels

工程技能以五个标准 triage 角色说话。本文件把这些角色映射到本仓库 issue tracker 实际使用的标签字符串。

| 标准角色（mattpocock/skills） | 本仓库标签            | 含义                                     |
| ----------------------------- | --------------------- | ---------------------------------------- |
| `needs-triage`                | `needs-triage`        | 维护者需要评估该 issue                    |
| `needs-info`                  | `needs-info`          | 等待报告者补充信息                        |
| `ready-for-agent`             | `ready-for-agent`     | 已完全规格化，可交给 AFK agent 实施       |
| `ready-for-human`             | `ready-for-human`     | 需要人来实现                              |
| `wontfix`                     | `wontfix`             | 不会处理                                  |

当某个技能提到某个角色（如"打上 AFK-ready 的 triage 标签"）时，使用上表对应的标签字符串。

要改用自定义词汇，编辑右列即可。
