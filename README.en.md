# Orch — Industrial Device Control & Orchestration Platform (English stub)

Open-source (Apache-2.0) industrial device control and orchestration platform:
unified tag-model southbound driver plugins (Modbus / OPC UA / MQTT-Sparkplug /
HTTP / frame templates), a visual flow-orchestration engine, ISA-18.2 alarms,
RBAC + audit, northbound MES/MQTT integration, and a Vite + React web UI.
